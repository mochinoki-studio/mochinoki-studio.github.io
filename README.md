# 모찌노키 스튜디오 웹사이트

https://mochinoki-studio.github.io/

| 주소 | 앱 | 만드는 곳 |
| --- | --- | --- |
| `/` | 스튜디오 대문 | 이 레포의 `index.html` (직접 고침) |
| `/mochi-noki/` | 모찌 노키 (Mac) | `mochi-noki` 레포 `python3 design/site/build.py` |
| `/memory-pieces/` | Memory Pieces | `memory-pieces-ios` 레포 `python3 docs/site/build.py` |
| `/logic/` | 모찌노키 로직 | `mochinoki-logic` 레포 `python3 tools/site/build.py` |

앱 폴더는 각 앱 레포의 생성기가 통째로 다시 만들어요. 그 폴더 안의 파일은 직접 고치지 말고 생성기를 고친 뒤 다시 실행해 주세요.
생성기는 이 레포가 앱 레포 옆이나 한 단계 위 폴더에 있으면 자동으로 찾아요.
