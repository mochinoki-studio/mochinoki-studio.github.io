Memory Pieces プライバシーポリシー

施行日: 2026年11月17日 · バージョン 1.0

このポリシーは、iPhone・iPad と Android 向けアプリ「Memory Pieces」（以下「本アプリ」）とこのウェブサイトで、Memory Pieces の運営者（以下「運営者」）が情報をどう扱うかを説明します。韓国の個人情報保護法（第30条）が定める構成に沿っています。

この日本語版は参考のための翻訳です。正式な文書は韓国語版で、内容が異なる場合は韓国語版が優先されます。

ひと目でわかる
📷 写真は端末の中だけ選んだ写真、パズル、思い出、メモ、ベストタイムは端末の中だけに保存され、運営者には届きません。 🙅 アカウントもサーバーもなし会員登録も、運営者のサーバーも、分析ツールもありません。 📢 広告は Google無料版の広告は Google AdMob が表示します。広告のために Google が端末情報の一部を収集することがあり、いつでも制限・オフにできます。 💳 支払いはストア「広告を削除」の支払いは Apple・Google が処理し、運営者は支払い情報を見ません。

1. 情報を扱う目的

運営者は次の目的のためだけに情報を扱い、目的が変わる場合は韓国の個人情報保護法第18条に従って必要な措置をとります。

  • 写真からジグソーパズルを作り、進行状況を保存し、完成したパズルを思い出アルバムに残す機能の提供
  • 無料版での広告表示（Google AdMob 経由）と、法律で必要な場合の広告への同意の取得
  • 「広告を削除」の購入状況の確認
  • お問い合わせへの対応（メールなどで直接ご連絡いただいた場合）

運営者は情報を上記以外の目的に使いません。販売したり、利用者のプロフィールを作ったり、他の情報と結びつけたりしません。

2. 扱う情報の項目

① 端末の中だけで扱う情報

パズル機能はすべて端末の中で動きます。次の情報はアプリ専用の保存領域にだけ保存され、運営者には送られず、削除したりアプリを削除したりすると消えます。

  • 写真: 選んだ写真をパズル用に切り抜いたコピーと小さなサムネイル。思い出には撮影日だけを表示し、写真の位置情報は使いません。
  • パズルの進行状況: ピースの位置、プレイ時間、使ったヒントの数、ガイド画像の使用有無
  • 思い出: 完成したパズル、完成日、タイム、ピース数、あなたが書いたメモ
  • ベストタイムと設定: 難易度ごとのベストタイム、BGM・効果音・触覚・ボードテーマ
  • 広告の状態: 全画面広告を表示した回数と時刻（表示頻度の調整用）、広告への同意の結果
  • 購入状態: 「広告を削除」の購入有無（オフラインでも広告なしで起動するため）

本アプリはシステムの写真ピッカーを使い、選んだ写真だけを1枚ずつ読み込みます。写真ライブラリ全体、カメラ、マイク、連絡先、位置情報へのアクセスは求めません。

② 端末の外に送られる情報（広告、無料版）

無料版には Google の広告 SDK（Google Mobile Ads、User Messaging Platform）が含まれます。広告をリクエストするとき、これらの SDK が次の情報を Google に直接送ります。運営者はこの情報を受け取りません。

項目広告識別子（iPhone の IDFA はトラッキングを許可した場合のみ、Android は広告 ID・アプリセット ID）、IP アドレスとそこから推定されるおおよその位置、端末・OS・アプリの情報（機種、OS バージョン、言語、アプリのバージョン）、広告の表示・タップなどの操作、広告 SDK の診断情報
目的広告の表示と頻度の制限、効果測定、不正防止、（同意した場合）パーソナライズ広告
受領者Google LLC（Google のサービスを使用するサイトやアプリから収集した情報の Google による使用、Google プライバシーポリシー）

「広告を削除」を購入すると、広告 SDK は広告をリクエストしません。App Store と Google Play のアプリのプライバシー情報にも、この広告関連の情報だけを記載しています。

③ 支払い

「広告を削除」は買い切りのアプリ内課金で、Apple の App Store または Google Play が直接処理します。運営者が氏名、カード、支払い情報、ストアのアカウント情報を受け取ることはなく、本アプリは購入済みかどうかだけを確認します。支払いの処理は Apple のプライバシーポリシーと Google プライバシーポリシーに従います。利用規約は、iPhone・iPad では Apple の標準使用許諾契約（EULA）、Android では Google Play 利用規約に従います。

④ あなたが自分で送る情報

  • 共有: 思い出の「共有」を押すと、あなたが選んだアプリ（メッセージ、写真など）に写真のコピーが渡ります。送り先はあなたが決め、運営者には届きません。
  • お問い合わせ: メールでお問い合わせいただくと、運営者はメールアドレスと内容（あなたが書いた端末・アプリの情報を含む）を受け取ります。

3. 14歳未満のお子さま

本アプリは主に14歳未満のお子さまを対象としておらず、運営者はお子さまを含め誰の個人情報も直接収集しません。広告は一般向けとしてリクエストされます。14歳未満のお子さまからメールが届いた場合は、法定代理人の同意なしに回答に必要な範囲を超えて使わず、気づいた時点で削除します。

4. 保存期間

  • 端末内の情報: 削除するかアプリを削除するまで、あなたの端末にあります。運営者は保存しません。
  • 広告関連の情報: Google が自社のポリシーに従って保存します。運営者は受け取りません。
  • メールでのお問い合わせ: 対応後1年間保存して削除します。ご希望があればすぐに削除します。

5. 削除の方法

  • 思い出ひとつ: 思い出の詳細画面で「削除」を押すと、その写真と記録が消えます（ベストタイムは残ります）。
  • 途中のパズル: パズルの引き出しで長押しして「引き出しから外す」を選ぶと、写真と進行状況が消えます。
  • すべて: アプリを削除すると、本アプリが保存したすべての情報が消えます。
  • 端末のバックアップ: 端末のバックアップ（iCloud バックアップ、Google バックアップ）をオンにしている場合、そこにも本アプリのデータが含まれることがあります。バックアップは Apple・Google のアカウント設定から削除できます。
  • メール: 保存期間が過ぎたら、復元できない方法でメールボックスから削除します。

6. 第三者への提供

運営者は個人情報を第三者に提供したり販売したりしません。ただし無料版では、Google の広告 SDK が第2項②の情報を Google に直接送ります。これは運営者が持つ情報を渡すものではなく、第14項の方法で拒否・制限できます。

  • 支払い: Apple・Google が直接処理します（第2項③）。

7. 追加的な利用

該当しません。当初の目的に関連する範囲を超えて情報を利用・提供しません。

8. 処理の委託

該当しません。サーバーを運営していないため、処理を委託しません。

9. 国外への移転

運営者自身は情報を国外に送りません。無料版で広告をリクエストするとき、次のとおり情報が国外に送られます。

移転先Google LLC（プライバシーの問い合わせ: Google プライバシーお問い合わせフォーム）
移転先の国米国など Google のデータセンターがある国
時期と方法アプリ使用中に広告をリクエストするたびに、ネットワーク（HTTPS）で送信
項目第2項②の項目
目的広告の表示・測定、不正防止、同意した場合のパーソナライズ広告
保存期間Google のポリシーに従う
拒否の方法ATT でトラッキングを拒否する、アプリの「プライバシーの選択」、Android の広告 ID の削除でパーソナライズ広告を拒否できます。広告の送信自体を止めたい場合は「広告を削除」を購入してください。パズル機能はすべてそのまま使えます。

10. 安全管理措置

  • パズルの情報は、OS が保護するアプリ専用の保存領域、つまりあなたの端末の中にだけ置きます。運営者のサーバーやアカウントの仕組みはありません。
  • 写真はシステムの写真ピッカーで選んだものだけを読み込み、ライブラリ全体へのアクセスは求めません。
  • 広告と支払いの通信は暗号化（HTTPS）されています。

11. センシティブな情報

運営者はセンシティブな情報を扱いません。ただし、選んだ写真には顔などセンシティブな内容が写っていることがあります。写真は端末の中だけに保存され、「共有」を押したときだけあなたが選んだ先に渡るので、共有前に内容をご確認ください。

12. 仮名情報

該当しません。仮名情報は扱いません。

13. 自動収集の仕組みと拒否の方法

本アプリには運営者の Cookie や分析ツールはありません。無料版の Google 広告 SDK は広告識別子と端末の保存領域を使います（iPhone では、ATT で許可した場合のみ IDFA を使います）。拒否の方法は第14項にあります。

このウェブサイトは、ライト・ダークの表示モードの選択だけをブラウザのローカルストレージに記憶し、運営者には送りません。サイトは GitHub Pages で提供されているため、GitHub が IP アドレスなどのアクセス記録を残すことがあります（GitHub プライバシーステートメント）。ウェブフォントは Google Fonts から読み込むため、Google が IP アドレスなどの接続情報を受け取ることがあります。

14. 行動情報と広告の選択

運営者は行動情報を直接収集しません。無料版では、Google がパーソナライズ広告のために広告識別子や広告の操作などの行動情報を扱うことがあります。次の方法でいつでも拒否・制限できます。

  • iPhone・iPad: 初回起動時の確認画面で「App にトラッキングしないように要求」を選ぶか、「設定 › プライバシーとセキュリティ › トラッキング」でオフにする
  • アプリ内: 同意が必要な地域（EEA、英国など）では「設定 › プライバシーの選択」で同意を変更・撤回する
  • Android: 「設定 › プライバシー › 広告」（端末により名称が異なります）で広告 ID をリセットまたは削除する
  • 広告をすべてなくす: 買い切りの「広告を削除」

15. あなたの権利と行使方法

あなた（14歳未満の場合は法定代理人）は、いつでも個人情報の閲覧・訂正・削除・処理の停止を求めることができます。パズルの情報はあなたの端末にだけあるので、ほとんどはアプリ内ですぐにできます。

  • 閲覧: パズルの引き出し、思い出アルバム、「設定 › ベストタイム」で見られます。
  • 訂正: 思い出のメモは詳細画面ですぐに直せます。
  • 削除: 思い出・パズルをひとつずつ削除するか、アプリを削除してすべて消します（第5項）。
  • 処理の停止・同意の撤回: 広告関連の処理は第14項の方法で止められます。パズル機能はそのまま使えます。
  • Google が持つ広告関連の情報は、Google のプライバシーツール（Google アカウント › データとプライバシー）でご請求ください。
  • 運営者が持つ情報は、お送りいただいたメールだけです。下記の保護責任者に閲覧・削除をご請求いただければ、遅滞なく（遅くとも10日以内に）対応します。

韓国以外にお住まいの方は、お住まいの地域の法律（EU・英国の GDPR、カリフォルニア州の CCPA/CPRA など）による権利も同じ方法で行使できます。運営者は個人情報を販売・共有（クロスコンテキスト行動広告目的を含む）せず、権利の行使を理由に不利益な扱いをしません。
