How to play

  1. Each board has a candy box Kongkong must reach. Look at the walls and number candies first.
  2. Tap the cards below to line up commands in order. When a move repeats, put it inside a repeat card.
  3. Press Run and Kongkong follows your cards. If it bumps a wall or the candy sum is wrong, fix your plan and try again.
  4. Reach the box and earn stars for using few cards. Try again with fewer cards to collect all three.

Thinking grows as you play

🃏 Step-by-step thinking

Start with arrow cards, then repeat cards and "until blocked" condition cards. Learn the basic ideas of coding through puzzles.

🔢 Sorting races

Sort the blocks from smallest to largest within a set number of swaps. Boards that only swap neighbors and boards that swap any two each need a different strategy.

🗺️ Worlds that follow the curriculum

From the Number Factory, Times Table Farm and Fraction Bakery to the Function Lab and Calculus Sled Hill, the math in the puzzles grows in the order kids learn it.

🎨 Your own Kongkong
